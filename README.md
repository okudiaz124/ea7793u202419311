# TrailQuest Adventure Camps

Angular application for managing adventure camp reservations and capacity.

## Requirements

- Node.js and npm

## Run

```bash
npm install
npm start
```

## Stack

Angular 22, TypeScript, Angular Material, ngx-translate and json-server.
